# Google Play Store Listing — Working Draft

This draft is intentionally factual. Do not add a feature until the exact release build contains it.

## App name
Safir Scanner

## Short description
Scan documents, edit pages and create multi-page PDFs on your device.

## Full description
Safir Scanner helps you turn paper documents or existing images into clean multi-page PDF files on Android.

Capture pages with your camera or import images from your device. Safir Scanner can detect document edges and correct perspective, while manual editing controls let you fine-tune the result before export.

Features in the current product:
- document capture with camera;
- image import as an alternative to camera capture;
- automatic document-edge detection and perspective correction;
- manual perspective crop;
- multi-page scans;
- page rotation and reordering;
- Original, Color+, Gray, B&W and Contrast filters;
- local multi-page PDF creation;
- open and share saved PDFs through Android;
- delete saved PDFs with confirmation;
- no account required for the scanner workflow.

Document content in the core scanner flow is processed locally by Safir Scanner. Advertising/privacy wording must be re-checked after the exact production AdMob build is finalized.
